# Kunuz — Cultural Heritage Platform

Landing page hero section for Kunuz, a platform dedicated to Algeria's cultural heritage.

## Assets

Place these files in the `public/` folder:

- **kunuz-logo.svg** — Your logo (a placeholder geometric emblem is included)
- **hero-bg.jpg** — Hero background image (Algerian/Moorish architecture)

To use your own hero image, update `src/components/Hero.tsx` and change `HERO_IMAGE` to `"/hero-bg.jpg"`.

## Run

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Tech

- Next.js 16 (App Router)
- Tailwind CSS v4
- Lato (body/UI) + Playfair Display (brand name, Alcoholica alternative)
